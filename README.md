# Projects 5D – Data Repository

## Overview

**Projects 5D** are supervised (tutored) projects carried out by undergraduate students at SupBiotech.  
These projects are designed to introduce students to:

- Project management in a scientific context  
- Innovation in biotechnology  
- Team-based problem solving  
- Data generation, analysis, and communication  

This repository serves as a centralized location for storing, organizing, and sharing the data generated during these projects.

---

## Objectives of Projects 5D

The Projects 5D program aims to:

- Provide hands-on experience in managing a scientific project from concept to results  
- Encourage innovation and creativity in biotechnology  
- Develop skills in experimental design, data analysis, and interpretation  
- Promote collaboration and communication within multidisciplinary teams
